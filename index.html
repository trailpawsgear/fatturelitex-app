Fattura elettronica pronta in un minuto

Compila i dati, scarica il file XML conforme allo standard FatturaPA, pronto da caricare sul portale Fatture e Corrispettivi o sul software del tuo intermediario. Tutto nel tuo browser: nessun dato lascia questo computer.

Nota importante: questo strumento genera un file XML conforme allo standard FatturaPA per il regime forfettario (RF19), pronto per l'invio tramite il portale "Fatture e Corrispettivi" dell'Agenzia delle Entrate, un intermediario abilitato o il software del tuo commercialista. Non invia la fattura al Sistema di Interscambio al posto tuo e non sostituisce la consulenza del tuo commercialista: verifica sempre i dati, in particolare l'imposta di bollo e la numerazione progressiva, prima di trasmettere la fattura.
